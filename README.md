# SfHPC_project
individual project on the discipline of Software for High-Performance Computing
## Пояснение
В репозитории 5 папок с заданиями. В них папки с решениями на разных фреймворках. README к каждому решению прилагается.
## Окружение
Используемые технологии:
 - компилятор -- clang 18.1.3
 - генератор -- ninja 1.11.1
 - C++ -- ни в одном CMakeLists.txt не зафиксирован, но реально использовался (выставлен по умолчанию) C++17  

Характеристики ЭВМ:
 - CPU -- Intel(R) Core(TM) i5-3210M CPU @ 2.50GHz
 - Memory -- 16GB DDR3
 - Storage -- SSD 256GB
 - GPU -- Intel Corporation 3rd Gen Core processor Graphics Controller -- нигде реально не использовался, в OpenCL использовался CPU
