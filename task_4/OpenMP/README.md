# Задание 4
## ТЗ
Вычислить число $\pi$ методом Монте-Карло.
## Сборка
Используется классика -- cmake. Думаю дальнейшие объяснения излишни. Необходимо наличие фреймворка OpenMP, само ничего скачиваться не будет.
## Реализация
Пропущу математическое обоснования, в виду популярности задачи. Скажу лишь, что я считаю эмпирическую вероятность попадания точки в четверть круга с $R=1$. Потоки делят между собой точки, они их по-отдельности проверяют, после чего результаты складываются.
