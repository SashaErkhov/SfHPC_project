# Задание 4
## ТЗ
Найти максимум в массиве данных и посчитать сколько раз этот максимум встречается во всем массиве.
## Сборка
Используется классика -- cmake. Думаю дальнейшие объяснения излишни. Необходимо наличие фреймворка OpenMP, само ничего скачиваться не будет.
## Реализация
Каждый поток проверяет отдельно свою часть массива, потом среди них выбирается глобальный максимум.
