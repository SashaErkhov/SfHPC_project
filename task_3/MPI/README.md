# Задание 3
## ТЗ
Умножить матрицу на вектор. Показать зависимость времени работы от размера входных данных.
## Сборка
Используется классика -- cmake. Думаю дальнейшие объяснения излишни. Необходимо наличие фреймворка MPI, само ничего скачиваться не будет.
## Запуск
```shell
mpirun ./task_1
```
Здесь задача распараллеливается на количество ядер. Или:
```shell
mpirun --use-hwthread-cpus ./task_1
```
Здесь задача распараллеливается на количество апаратных потоков.
## Реализация 
Добавил побольше комментариев, все, что следует упомянуть, расписал в них.
