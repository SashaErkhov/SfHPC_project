# Задание 3
## ТЗ
Умножить матрицу на вектор. Показать зависимость времени работы от размера входных данных.
## Сборка
Используется классика -- cmake. Думаю дальнейшие объяснения излишни. Необходимо наличие фреймворка OpenMP, само ничего скачиваться не будет.
## Реализация
Разница с предыдущей задачей в том, что тут нет общей области памяти, в которой может развится гонка, из-за чего и изменилась директива
