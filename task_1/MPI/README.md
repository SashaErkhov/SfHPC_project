# Задание 1
## ТЗ
Вывести на экран сообщение из каждого потока по отдельности.
## Сборка
Используется классика -- cmake. Думаю дальнейшие объяснения излишни. Необходимо наличие фреймворка MPI, само ничего скачиваться не будет.
## Запуск
```shell
mpirun ./task_1
```
Здесь задача распараллеливается на количество ядер. Или:
```shell
mpirun --use-hwthread-cpus ./task_1
```
Здесь задача распараллеливается на количество апаратных потоков.
## Реализация 
Тут все очевидно. Для того, чтобы было понятно, что сообщения пишутся с разных потоков и было понятно какое сообщение с какого, в сообщение была добавлена необходимая информация.
