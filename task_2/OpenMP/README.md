# Задание 2
## ТЗ
Посчитать сумму массива чисел. Показать зависимость времени работы программы от количества чисел в массиве (10, 1000, 10000000).
## Сборка
Используется классика -- cmake. Думаю дальнейшие объяснения излишни. Необходимо наличие фреймворка OpenMP, само ничего скачиваться не будет.
## Реализация 
Тут всё очевидно, кроме директивы в функции foo, она позволяет распараллелить цикл, в каждом потоке создается копия переменной, выполняется часть цикла, потом все объединяется.
## Итог
Для 1000 символов получается быстрее чем для 10. Вероятно, больше пространства для распараллеливания. Сравнительная таблица для 10-ти экспериментов:  
| N | Среднее время |
| :-: | :---: |
| 10 | 0.003980844 |
| 1000 | 0.0014968151 |
| 10000000 | 0.02258365 |
